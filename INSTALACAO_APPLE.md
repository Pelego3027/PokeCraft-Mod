# 📱 Guia de Instalação Rápida - PokeCraft no Apple (iOS/iPad)

## ⚡ Método Rápido (Recomendado)

### Passo 1: Baixe o Minecraft Realms+
```
1. Abra a App Store no seu iPad/iPhone
2. Procure por "Minecraft"
3. Baixe "Minecraft" (versão oficial)
4. Compre ou teste o Realms+ (7 dias grátis)
```

### Passo 2: Importe o PokeCraft
```
1. No PC/Mac, clone o repositório:
   git clone https://github.com/Pelego3027/PokeCraft-Mod.git

2. Comprima as pastas:
   - behavior_pack.zip
   - resource_pack.zip

3. Acesse seu Realms no Minecraft (PC)
4. Faça upload dos arquivos .zip
5. Aguarde a sincronização
```

### Passo 3: Acesse no iPad
```
1. Abra Minecraft no iPad
2. Vá em "Realms"
3. Selecione o mundo PokeCraft
4. Jogue! 🎮
```

---

## 🛠️ Método Alternativo: Usando Toolbox for Minecraft

### Passo 1: Baixe a App
```
1. Vá para App Store
2. Procure "Toolbox for Minecraft"
3. Baixe (versão gratuita disponível)
```

### Passo 2: Importe o Add-on
```
1. Abra Toolbox for Minecraft
2. Vá em "Add-ons"
3. Clique em "+"
4. Selecione os arquivos .mcaddon do PokeCraft
5. Importe para Minecraft
```

### Passo 3: Jogue
```
1. Abra Minecraft
2. Crie um novo mundo
3. Ative o add-on PokeCraft
4. Aproveite! 🎮
```

---

## ☁️ Método 3: Cloud Sync (OneDrive/iCloud)

### Passo 1: Prepare no PC
```
1. Configure o mod no Windows/Mac
2. Copie a pasta "minecraftWorlds" para OneDrive
```

### Passo 2: Sincronize
```
1. Abra OneDrive no iPad
2. Baixe os arquivos
3. Abra com Minecraft
```

## ⚠️ Problemas Comuns

### "Add-on não aparece"
- ✅ Reinicie o Minecraft
- ✅ Verifique o espaço disponível
- ✅ Tente novamente

### "Mundo não sincroniza"
- ✅ Conecte-se a Wi-Fi
- ✅ Aguarde alguns minutos
- ✅ Reinicie o app

### "Comandos não funcionam"
- ✅ Ative Cheats no mundo
- ✅ Reinicie o jogo
- ✅ Tente `/poke help`
