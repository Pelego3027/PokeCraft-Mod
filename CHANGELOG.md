# PokeCraft - Changelog

## [1.0.0] - Setembro 2026

### ✨ Recursos Adicionados
- ✅ Sistema completo de Pokémons (15 Pokémons iniciais)
- ✅ Sistema de captura com 4 tipos de Pokébolas
- ✅ Sistema de batalhas PvP com cálculo de dano realista
- ✅ Sistema de evoluções (evolução por nível)
- ✅ Inventário completo com múltiplos tipos de itens
- ✅ Sistema de economia (compra/venda de itens)
- ✅ Pokédex para rastreamento de Pokémons
- ✅ Time de até 6 Pokémons
- ✅ Poções de cura (Poção, Super Poção, Hiperpoção, Restauração Total)
- ✅ Itens de status (Antídoto, Despertador, Cura Total)
- ✅ Doce Raro para aumentar nível
- ✅ Pedras de Evolução (Fogo, Água, Trovão, Folha)

### 📝 Comandos Implementados
- `/poke getstarter` - Obter Pokémon inicial
- `/poke team` - Ver time
- `/poke pokedex` - Ver Pokédex
- `/poke inventory` - Ver inventário
- `/poke buy` - Comprar itens
- `/poke useitem` - Usar itens
- `/poke status` - Ver status de Pokémon
- `/poke evolve` - Evoluir Pokémon
- `/poke battle` - Iniciar batalha
- `/poke help` - Ajuda
